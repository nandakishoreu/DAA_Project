SEARCH + PRUNING

The algorithm explores include/exclude decisions. It calculates an optimistic upper bound for each partial basket. If that bound cannot beat the best solution already found, the branch is pruned.

05

Complexity analysis

THEORY
O(2ⁿ)

In the worst case, the algorithm may explore every include/exclude combination. Bounding can reduce the search in practice.

O(n)

Depth-first recursion stores a path of at most n decisions, excluding the input and trace output.

n = number of products. This implementation uses a fractional-knapsack upper bound after sorting by value-to-cost ratio. The bound is optimistic; products themselves remain indivisible (0/1 choices).

06

How the algorithm works

0/1 KNAPSACK · BRANCH & BOUND
01

Sort

Arrange products by value-to-cost ratio to calculate a useful upper bound.

02

Branch

For each product, create two choices: include it or exclude it.

03

Bound

Estimate the best possible value reachable from the current partial basket.

04

Prune

Stop exploring a branch if it exceeds the budget or cannot beat the best value.
